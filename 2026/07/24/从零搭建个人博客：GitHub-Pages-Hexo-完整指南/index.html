从零搭建个人博客：GitHub Pages + Hexo 完整指南

  • 2026-07-24
  • 作者 Simple
  • ~5.92K 字

在互联网时代，拥有一个属于自己的个人博客，不仅是技术能力的体现，更是分享知识、记录成长的重要平台。相比使用第三方博客平台，自建博客能让你完全掌控内容与样式。本文将带你从零开始，使用 Hexo + GitHub Pages 搭建一个完全免费、可自定义的个人博客。

一、为什么选择 Hexo + GitHub Pages？

很多人刚开始写技术博客时，通常会选择 CSDN、掘金、博客园等平台。这些平台的好处是流量大、发布方便，但也存在一些限制：页面样式由平台决定，个性化空间有限；文章数据主要托管在第三方平台；而且广告和平台规则会影响阅读体验。

而 Hexo + GitHub Pages 的方案可以很好地解决这些问题：

  • 零成本：GitHub Pages 提供免费的静态网站托管服务，无需购买服务器和域名。
  • 高效轻便：Hexo 是基于 Node.js 的静态博客框架，支持 Markdown 写作，生成速度极快。
  • 高度可定制：拥有丰富的主题和插件生态，可轻松实现代码高亮、评论系统等功能。
  • 版本管理：所有博客源码和文章都保存在 GitHub 仓库中，方便备份和多设备同步。

简单来说，这套方案的工作流程是：你用 Markdown 写文章，Hexo 把文章生成为静态网页，最后 GitHub Pages 把生成后的网站免费发布到互联网上。

三、创建 GitHub 仓库

在 GitHub 上创建一个仓库来存放博客的静态文件。

  1. 登录 GitHub，点击右上角的“+”号，选择 New repository
  2. 在 Repository name 处填写仓库名，格式必须为：你的用户名.github.io（例如用户名为 zhangsan，则仓库名为 zhangsan.github.io）
  3. 仓库权限设置为 Public（公开），否则无法正常访问
  4. 点击 Create repository 完成创建

创建完成后，你的博客访问地址就是 https://你的用户名.github.io。

八、常见问题与注意事项

8.1 国内访问 GitHub 速度慢

国内访问 GitHub 的网络状况有时不太理想。可以尝试以下方法：

  • 使用 GitHub 镜像加速
  • 配置代理或 VPN
  • 考虑使用 Gitee Pages 作为备选方案

8.2 自定义域名

如果你想使用自己的域名，可以在 source/ 文件夹中创建一个名为 CNAME 的文件，里面写入你的域名。然后在 GitHub 仓库的 Settings > Pages 中配置自定义域名，并完成 DNS 解析设置。

8.3 SEO 收录

GitHub Pages 的二级域名（username.github.io）在百度的 SEO 收录效果可能不太理想。如果需要更好的 SEO 效果，建议绑定自定义域名，Google 和必应可以正常收录 github.io 网站。

8.4 数据备份

建议采用双仓库方案：一个仓库存放 Hexo 源码和 Markdown 文章（用于备份和同步），另一个仓库（username.github.io）存放生成的静态文件（用于 Pages 部署）。
